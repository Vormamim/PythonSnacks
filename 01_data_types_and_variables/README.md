# Data Types and Variables

This folder helps beginners practise the basic building blocks of Python: variables and data types.

In Python, a variable stores a value. The value can be a number, a word, a true/false value, or a collection of items.

## What you will learn

- how to create variables
- the difference between strings, integers, floats, and booleans
- how to print values from variables
- how to change a variable's value
- how to combine variables with text

## Key idea

```python
name = "Vera"
age = 18
member = True
```

Here:

- `name` is a string
- `age` is an integer
- `member` is a boolean

## Common data types

### String
A string stores text.

```python
name = "Luna"
```

### Integer
An integer stores whole numbers.

```python
age = 25
```

### Float
A float stores numbers with decimal places.

```python
price = 12.50
```

### Boolean
A boolean stores `True` or `False`.

```python
member = True
```

## Theory notes

### Variables
A variable is a name that stores a value.

```python
player_name = "Ari"
```

### Assignment
We use `=` to give a variable a value.

```python
score = 10
```

### Reassignment
We can change the value later.

```python
score = 15
```

### Printing variables

```python
print(player_name)
```

This shows the stored value in the output.

### Combining text and values

```python
print("Hello, " + name)
```

This joins text with the value of the variable.

## Beginner tip

Always choose clear variable names.

Good examples:

- `name`
- `age`
- `price`
- `member_status`

Bad examples:

- `x`
- `y`
- `thing`

Clear names make code easier to understand.
