# Python Snacks

This is a beginner-friendly collection of small Python learning activities.

The goal is simple: help students learn Python step by step using short, clear examples and easy exercises. Each folder focuses on one idea at a time, so it is easier to understand and practise.

---

## How to use this project

Start at the beginning of the sequence and work through each folder in order.

Do not rush ahead. Try each example, change the values, and run the script again. That helps you understand what the code is doing.

A good beginner pattern is:

1. Read the README for the folder
2. Look at the sample scripts
3. Run the script
4. Change a value and run it again
5. Try the exercises at the end

---

## Learning sequence

The folders are ordered from the simplest ideas to more advanced ones.

### 1. 01_data_types_and_variables

This is where beginners start.

Learn about:

- variables
- strings
- integers
- floats
- booleans
- changing values

### 2. 02_boolean_logic

This folder teaches how Python makes decisions using `True` and `False`.

Learn about:

- `if`
- `elif`
- `else`
- booleans with variables and lists

### 3. 03_if_elif_else

This is a simple set for decision-making with conditions.

Learn about:

- checking values
- making choices
- using comparison operators
- deciding between different possible answers

### 4. 04_lists

Lists are one of the most important Python ideas.

Learn about:

- creating lists
- accessing items
- checking if something is inside a list
- changing list items

### 5. 05_working_with_lists

This continues the list work and shows more practical examples.

Learn about:

- adding items
- removing items
- finding values
- using lists in decisions

### 6. 06_loops

This introduces loops, which repeat code.

Learn about:

- `for` loops
- `while` loops
- counting
- repeating actions

### 7. 07_nested_loops

This is a step up from regular loops.

Learn about:

- loops inside loops
- tables and grids
- repeating patterns
- combining lists in a simple way

### 8. 08_dictionaries

Dictionaries store data as key-value pairs.

Learn about:

- keys and values
- creating dictionaries
- reading values
- updating values

### 9. 09_searching_lists_and_dicts

This teaches the idea of searching for information.

Learn about:

- checking if a value is in a list
- checking if a key exists in a dictionary
- finding a matching item

### 10. 10_functions

Functions are reusable blocks of code.

Learn about:

- defining a function
- calling a function
- using parameters
- returning values

### 11. 11_operators

This folder looks at operators in Python.

Learn about:

- arithmetic operators
- comparison operators
- logical operators
- using operators inside decisions

### 12. 12_random_module

This introduces the `random` module.

Learn about:

- generating random numbers
- choosing random items
- simple game-style examples

## Demos folder

The final folder is:

- 99_demos

This folder holds larger, themed example projects that bring the learning together.

### 99_demos / adventure_game

This is a simple vampire-themed text adventure example.

It shows how beginner Python ideas can be used in a game.

### 99_demos / record_shop_snacks

This is a themed record shop demo.

It uses products, prices, stock, and recommendations to show how lists and dictionaries can be used in a realistic example.

These demo folders are not the start of the learning sequence. They are meant to be used after the main skill folders, as practice or inspiration.

---

## Beginner advice

Python is easier when you practise slowly.

Try these habits:

- run one script at a time
- change one value at a time
- read the error messages
- ask: "What is changing?"
- compare the output with the code

A lot of learning happens by experimenting.

---

## Suggested path for students

If you are new to Python, use this order:

1. Start with variables and data types
2. Learn booleans and decisions
3. Practise lists
4. Learn loops
5. Learn dictionaries
6. Learn functions
7. Try the demos at the end

---

## Final note

These files are intentionally short and simple so they are easy to read.

They are designed for beginners who want to build confidence with small, clear examples.

If you keep trying, changing, and testing, Python will start to make more sense.
