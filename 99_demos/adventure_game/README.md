# Vampire Adventure Game Code Snacks

Welcome to the Vampire Adventure Game Code Snacks! These beginner-friendly scripts use lists and dictionaries to build simple text adventure choices. The theme is a vampire world filled with castles, moonlit forests, ancient crypts, and dangerous decisions.

The goal is to help students understand decision making in Python using `if`, `elif`, and `else` without using functions or classes.

## What you will learn

- how to store game data in lists and dictionaries
- how to test values with `if` statements
- how to make different choices in a text adventure
- how to recommend actions based on player decisions
- how to build simple beginner-friendly game logic

## How to run a script

From the project folder, run:

```bash
python script_name.py
```

For example:

```bash
python 01_castle_gate.py
```

## Script list and theory

### 1. `01_castle_gate.py` - Choosing a castle gate
Theory:
This script stores a player's choice in a dictionary and uses an `if` statement to decide what happens next. The player picks a gate and the game responds with a different outcome based on that choice.

### 2. `02_blood_type.py` - Choosing a vampire blood type
Theory:
This script uses a dictionary of options and compares the player choice with a value. It shows how a simple condition can lead to different results.

### 3. `03_crypt_treasure.py` - Deciding whether to take treasure
Theory:
This script checks a player value against a danger level. The decision depends on whether the treasure is safe or cursed.

### 4. `04_midnight_forest.py` - Choosing a path through the forest
Theory:
This script uses a list of paths and a choice variable. The player picks a route, and the script shows the result using `if` and `elif`.

### 5. `05_vampire_friendly.py` - Meeting a vampire guest
Theory:
This script checks whether a character is friendly, suspicious, or a threat. It uses a series of conditions to decide the story outcome.

### 6. `06_recommendation.py` - Suggesting the best action
Theory:
This script uses a player's mood or goal to recommend a next step. It uses a decision chain to suggest the strongest choice.

### 7. `07_blood_budget.py` - Planning supplies
Theory:
This script compares a player's supply amount with a needed total. It teaches how to test whether a value is low, enough, or too much.

### 8. `08_ancient_vial.py` - Checking a magical item
Theory:
This script uses a dictionary to store information about a magical item and decides whether it is cursed, powerful, or safe.

### 9. `09_party_invite.py` - Inviting allies to a vampire party
Theory:
This script uses a list of guests and checks how many invitations have been sent. The decision depends on the number of items in the list.

### 10. `10_final_escape.py` - Ending the adventure
Theory:
This script combines a player's choices, health, and treasure to make a final decision. It shows how several conditions can work together in a simple adventure game.

## Beginner challenge ideas

Try changing these values:

- the names of the characters
- the possible choices
- the treasure values
- the danger level
- the ending outcomes

You can also add your own tiny adventure scene using the same pattern.

These scripts are meant to be easy to read, edit, and reuse.
