# Soviet Space Launch Simulator

This demo is a creative adventure inspired by the 1970s space race.

The story is set in a fictional Soviet mission control, where the player makes choices during a launch, an orbital emergency, and a lunar landing.

## Style

This folder uses a very simple, text-based adventure style.

It is intentionally written in a beginner-friendly way:

- no dictionaries
- no functions
- no advanced Python features
- simple choices and branching story paths

## Files

1. `01_launch_console.py` - launch countdown and early system decision
2. `02_orbit_choice.py` - orbital emergency during the mission
3. `03_lunar_landfall.py` - landing decision on the Moon

## Learning idea

This demo shows how a small text adventure can be built with:

- `print()` messages
- `input()` choices
- `if` and `else` decisions
- branching story outcomes

## Theme

The project mixes retro Soviet space imagery with a playful, beginner coding challenge.

It is a fun way to practise using conditions and story logic in Python.
