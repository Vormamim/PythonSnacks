# Collector

This is a simple starter version of the Collector game.

The full game is more complex, but this version is designed for beginners.
It keeps the basic idea:

- the board is a grid
- you place a mark on a square
- you remove a nearby empty square
- the biggest connected group wins

## Simple version

This demo uses a 4 by 4 board, not a 6 by 6 board.
This makes it much easier to play and understand.

## Rules

1. Choose a square to mark.
2. Choose a neighboring empty square to remove.
3. Diagonal moves are allowed.
4. Use the same letter for your marks.
5. After a few turns, count the biggest connected group.

## Beginner goal

This is not a full strategy game. It is a gentle introduction to:

- grids
- connected groups
- choosing valid moves
- simple turn-based play

## Possible extension

Students can later make it more advanced by adding:

- larger board sizes
- a full win check
- turn switching
- score counting
- a smarter move system
