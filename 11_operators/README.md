# Operators

This folder helps beginners learn the most common operators in Python.

Operators are symbols that let us do things like:

- add numbers
- compare values
- check if more than one condition is true
- combine conditions in decisions

## What you will learn

- arithmetic operators
- comparison operators
- logical operators
- how operators are used in if statements

## Arithmetic operators

These are used for maths.

```python
print(5 + 3)
print(10 - 2)
print(4 * 2)
print(9 / 3)
```

Examples:

- `+` adds
- `-` subtracts
- `*` multiplies
- `/` divides

## Comparison operators

These compare two values and return `True` or `False`.

```python
print(5 > 3)
print(4 == 4)
print(7 != 9)
```

Examples:

- `==` equal to
- `!=` not equal to
- `>` greater than
- `<` less than
- `>=` greater than or equal to
- `<=` less than or equal to

## Logical operators

These combine conditions.

```python
if age > 18 and member == True:
    print("Adult member")
```

Examples:

- `and` both conditions must be true
- `or` at least one condition must be true
- `not` reverses a condition
